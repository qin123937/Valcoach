# 知识层编辑指南 —— 想加"自己的理解"，改哪个文件

这个程序把"知识"拆成四层。**改不同层，动静完全不同**：

| 层 | 你写的是什么 | 改哪儿 | 会不会影响打分 |
|---|---|---|---|
| ① 数值层 | 某个英雄某方面几分、这张图需要几分 | `data/agents.js` 的 `vec`、`data/ascent.js` 的 `need` | **会**（直接影响分数与结论） |
| ② 语义层 | 这个道具到底能干什么、适合什么局面 | `data/agents.js` 的 `abilities[].note / adds / tip` | 不会（只影响文字和 AI 的措辞依据） |
| ③ 策略层 | 一套具体的打法：谁、什么顺序、丢哪、为什么 | `data/ascent.js` 的 `VD.COMBOS` | 不会（只影响"可用组合拳"列表与推荐理由） |
| ④ 表达层 | AI 教练的口吻、必须遵守的规则、禁用说法 | `js/app.js` 的 `SYS_PROMPT` | 不会 |

一句话：**"某个道具有多强" → ①；"某个道具拿来干什么" → ②；"五个人怎么配合" → ③；"AI 怎么说话" → ④。**

---

## 一、②语义层：加"对道具效果的理解"（最常改，最安全）

文件：`data/agents.js`，每个英雄是一个对象：

```js
{
  id: 'viper', name: '蝰蛇', en: 'Viper', role: '控场',
  vec: { smoke: 8, flash: 0, info: 1, control: 2, mobility: 0, sustain: 0, postplant: 4, econ: 4 },
  adds: ['长墙切割', '毒幕守包', '持续区域'],        // ← 三个短标签：她的价值点
  tip: '适合"守包/拖时间"型阵容……',                  // ← 一句话用法，显示在英雄池和推荐卡
  alt: [{ role: '哨卫', why: '毒幕能切掉一条进点路线……' }],   // ← 可选：兼职位
  abilities: [
    { name: '蛇吻', tag: '伤害', note: '…你能补充的实战理解…' },
    { name: '瘴云', tag: '烟',   note: '…' },
    { name: '毒幕', tag: '烟',   note: '…' },
    { name: '蝰腹', tag: '大招', note: '…' }
  ]
}
```

- `note` 就是你要补的"理解"：什么时候丢、丢哪、怕什么。它会出现在**英雄档案**里，也会进 `buildFacts` 交给 AI 当事实依据（AI 被要求只能引用这些内容，不许自己编）。
- `adds` 是短标签，会出现在推荐卡片的理由里。
- `tip` 是"一句话定位"，会出现在英雄池卡片和阵容体检的提示里。
- **只改字不会改变分数**，可以放心写。

## 二、③策略层：加"自己的战术"

文件：`data/ascent.js` 第 35 行起的 `VD.COMBOS`，一条 combo 长这样（这是 A 点双烟速攻的真实结构）：

```js
{
  id: 'a-exec-brim-sova-jett',          // 唯一 id，英文小写加连字符
  map: 'ascent', site: 'A', side: 'attack',
  title: 'A 点双烟速攻',                 // 卡片标题
  requires: ['brimstone', 'sova', 'jett'],   // 这 5 个人必须都在阵容里才算"可用"
  difficulty: 2,                          // 1 路人局能用 / 2 要沟通 / 3 要练
  steps: [
    { t: 0, agent: 'brimstone', ability: '空投烟幕', target: 'A 大出口 + 天堂', why: '两颗烟同时切掉正面枪线和天堂高点' },
    { t: 1.5, agent: 'sova', ability: '寻敌箭', target: 'A 点内侧墙（反弹进点）', why: '扫出点内站位' }
  ],
  win_condition: '把 A 点变成只能从酒窖/发电机补防的局部战场。',
  countered_by: ['对手奇乐/零提前在 A 大放陷阱', '对面双烟反封 A 大'],
  source: '自己排位总结 / 某场比赛'
}
```

三条硬约束（写错就不会显示或匹配不上）：

1. `requires`、`agent` 里的 id 必须存在于 `data/agents.js`（30 个 id 见该文件）；
2. `ability` 必须**一字不差**等于该英雄 `abilities[].name`（比如猎枭是"寻敌箭"不是"侦查箭"）；
3. `target` 里的点位名建议用 `data/ascent.js` 第 22–25 行 `callouts` 里已有的写法（A 大 / A 大厅 / A 点 / 天堂 / 发电机 / 酒窖 / 树屋 / 中路 / 中庭 / 中连 / B 大 / B 点 / 市场 / A 小 / CT 出生点 / B 后），因为 AI 被要求"点位只能用清单里的名字"。

写多了嫌麻烦？**不用改文件也能写**：点顶栏「战术」→「+ 新建战术」，一步一步选「几秒 / 谁 / 什么技能 / 打到哪 / 为什么」，保存即可（存本机、可导出 JSON）。面板里技能名只能从该英雄的技能里选、必要条件按用到的英雄自动生成，所以上面那三条硬约束它替你兜住了。

还有一个 Word 填表的形态：`docs/02-组合拳模板与导入格式.md` 是设计稿，`docs/组合拳模板.html` 可以直接在 Word 里填（导入功能还没接）。

## 三、①数值层：改"强弱判断"

| 想改什么 | 位置 |
|---|---|
| 某英雄烟/闪/信息/硬控/机动/续航/守包/经济各几分 | `data/agents.js` 每个英雄的 `vec`（烟 0–10，其余 0–5） |
| 这张图某一边需要多少 | `data/ascent.js` 第 14–21 行 `need.attack / need.defend`（单位=5 人合计，经济当前 14/15） |
| 8 个维度谁更重要 | `js/engine.js` 第 5–20 行 `DIMS[].w`（烟的 1.35 最高） |
| 多少算"缺口/偏弱/过剩" | `js/engine.js` 第 126–133 行（`n>=5 && c<0.6` 判缺口、`<0.85` 判偏弱、`s > n*overRatio` 判过剩） |

**不改文件也能改数值**：点顶栏「调参数」，30 个英雄的 8 个数字都能点着改（存浏览器本地，源文件不动，可"全部恢复默认"）。

## 五、改完自己怎么验（没有构建，改坏会白屏）

1. 顶部那条红条会显示 `文件名:行号`，看它就知道哪里写坏了；
2. 最常见的三个错：**少一个逗号**、**中文引号 "" 当成英文引号**、**技能名和 `agents.js` 不一致**（combo 不报错，只是匹配不到）；
3. 快速自检：打开页面 → 点「参考阵容」→ 组合拳卡片应该还是 2 条，第 5 人推荐列表有排名和 Δ。

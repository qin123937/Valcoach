# 组合拳模板与导入格式（v0.1，待你确认）

> 这一版只定"格式"，没有改任何代码。你看完给几句意见，我再接进程序。

## 一、要解决的事

现在 14 条组合拳是我写死在 `data/ascent.js` 里的。你要的是：**你自己（或者你队友、你看到的博主）能写一条新的组合拳，填完导入，程序立刻能认、能匹配、能进 AI 提示词。**

所以模板得同时满足两个互相拉扯的要求：

- **人写着舒服**：能在 Word 里填，不用碰代码、不用记括号逗号；
- **机器读得准**：字段固定、不靠自然语言猜测，导入时能逐格校验。

一句话方案：**两块表**——上面一块写"这套拳是什么"，下面一块写"每一步怎么打"。人在 Word 里填表，程序按表读格子。

## 二、模板长什么样

一套组合拳 = **主表（11 行键值）+ 步骤表（1 行 1 步）**。一个文档里可以并排放好几套，程序会逐块解析。

### 主表

| 项目 | 填写 |
|---|---|
| 名称 | A 点快打 · 双烟双闪 |
| 版本 | 11.08 |
| 地图 | 亚海悬城 |
| 阵营 | 进攻 |
| 目标区域 | A 点 |
| 难度 | 2 |
| 必需英雄 | 炼狱、猎枭、捷风 |
| 可选替代 | 炼狱→幽影；猎枭→黑梦 |
| 赢法（一句话） | 20 秒内三个人一起踩进 A 点，对面还没来得及回防 |
| 被什么破 | 对面在 A 大有狙击；我方烟被提前打散 |
| 作者 / 来源 | 自己 | 

### 步骤表

| 序 | 时间 | 谁 | 技能 | 从哪（站位） | 打到哪（落点） | 为什么（这一步改变了什么） |
|---|---|---|---|---|---|---|
| 1 | 0 秒 | 炼狱 | 空投烟幕 | A 大 | A 点 | 先封死包点视线，对面看不到我们进点 |
| 2 | 1 秒 | 猎枭 | 寻敌箭 | A 大 | 天堂 | 照出天堂有没有人，决定要不要先清 |
| 3 | 3 秒 | 炼狱 | 燃烧榴弹 | A 大 | 天堂 | 把天堂的人逼下来，不然我们进点会被点名 |
| 4 | 5 秒 | 捷风 | 逐风 | A 大 | A 点 | 第一个进点拉枪线，把注意力吸到自己身上 |
| 5 | 8 秒 | 猎枭 | 雷击箭 | A 大 | A 点 | 震掉包点近点的守点人，给捷风创造对枪优势 |

规则很简单：**一行 = 一个动作，按时间从上往下**。写不清楚"为什么"的那一步，通常就是这步其实没必要。

## 三、字段定义

### 主表字段

| 字段 | 必填 | 允许的值 | 备注 |
|---|---|---|---|
| 名称 | ✅ | 2–20 字 | 同一张图内不重名，重名导入时会提示改名 |
| 版本 | — | 如 `11.08` | 技能改动后好回溯；不填按"当前版本"处理 |
| 地图 | ✅ | 亚海悬城（后续加图后扩充） | 目前只做这一张 |
| 阵营 | ✅ | 进攻 / 防守 | 两个阵营的组合拳分开存 |
| 目标区域 | ✅ | 必须是该地图点位表里的名字：A 点 / B 点 / 中路 / A 大 / 天堂 / 中连 / 市场 … | 写不存在的名字会报错并列出可选值，避免"船屋"这类不存在的叫法 |
| 难度 | ✅ | 1 简单 / 2 普通 / 3 要练 | 影响卡片上的难度标记 |
| 必需英雄 | ✅ | 2–5 个国服英雄名，用「、」或逗号分隔 | 少于 2 个不算组合拳（那是单人道具），多于 5 个不可能凑齐 |
| 可选替代 | — | `A→B；C→D` | 只做展示，不参与匹配计算，避免"I 位换人就不认了" |
| 赢法 | ✅ | ≤ 40 字，一句话 | 必须说"打完得到什么"，不能写"打出配合"这种空话 |
| 被什么破 | — | ≤ 3 条，用「；」分隔 | 反向信息，AI 会用它提醒风险 |
| 作者 / 来源 | — | 名字或链接 | 自己写就写"自己" |

### 步骤表字段

| 字段 | 必填 | 允许的值 | 备注 |
|---|---|---|---|
| 序 | ✅ | 1、2、3… | 保持递增，导入时不会自动重排 |
| 时间 | ✅ | `0 秒` / `8 秒` / `1:20` | 只做展示，用来排顺序和让人看懂节奏 |
| 谁 | ✅ | 必须是主表"必需英雄"里的一个 | 名字不在里面 → 报错 |
| 技能 | ✅ | 必须是这个英雄技能表里的名字：炼狱 = 振奋信标 / 燃烧榴弹 / 空投烟幕 / 天基光束 | 写"烟雾弹""燃烧瓶"这类俗称 → 报错并提示正确写法 |
| 从哪（站位） | ✅ | 点位表里的名字 | 你说"释放位置"其实就是这个：站哪放 |
| 打到哪（落点） | ✅ | 点位表里的名字 | 区分"站哪放"和"落到哪"，因为半墙、跳投、地板弹全靠这个区别 |
| 为什么 | ✅ | ≤ 50 字 | **这一格是整张表最重要的**。写不出"这一步改变了什么"，AI 后面也没法讲清楚 |

步骤数量：**2–8 步**。一步的"组合拳"是道具演示，不是战术；超过 8 步没人记得住。

## 五、三种导入方式（推荐第一种）

### 方式 A（推荐）：Word 里填表 → 另存为「网页 (*.htm)」

1. 打开我给的 `组合拳模板.html`（Word 会当普通文档打开，表格可以直接打字）；
2. 复制一组空白块，填表；
3. **文件 → 另存为 → 网页 (*.htm, *.html)**；
4. 回到页面，点「导入组合拳」，选那个 .htm。

为什么推荐这个：Word 导出的 .htm 里表格结构是完整的，浏览器能精确读到每一格，**你完全不用关心格式**。而 Word 的 .docx 是压缩包，浏览器里拆它代价太大，所以不用 .docx 导入（.docx 你自己存档没问题）。

### 方式 B：Excel / 表格软件 → 「文本（制表符分隔）」.txt

一行一步，字段顺序固定：`序 时间 谁 技能 从哪 打到哪 为什么`，主表那 11 行用 `键: 值` 一行一条放在步骤前面，块与块之间空一行。适合你习惯用 Excel 排版的情况。

### 方式 C：JSON（高级，给会写代码的人）

直接给 `data/ascent.js` 的 `VD.COMBOS` 加一条，字段见下。也可以在页面里粘贴 JSON 导入，不落盘。

## 六、导入时会做什么校验

导入不做"猜"，全部按格子逐条检查，报错指到具体哪一格：

| 情况 | 提示 |
|---|---|
| 英雄名不在库里 | `第 2 块「B 点延迟守包」第 3 步：英雄"奇乐儿"不存在，最接近的是"奇乐"` |
| 技能名不在该英雄的技能表 | `第 1 块第 4 步：捷风没有"闪现"，可选：瞬云 / 凌空 / 逐风 / 飓刃` |
| 点名不在点位表 | `第 1 块第 2 步：点位"A 小道"不是亚海悬城的写法，可选：A 大 / A 大厅 / A 点 / 天堂 / 发电机 / 酒窖 / 树屋 / 中路 / 中庭 / 中连 / B 大 / B 点 / 市场` |
| 步骤里的英雄不在必需英雄里 | `第 3 块第 1 步：蝰蛇没写在"必需英雄"里，匹配时这套拳永远不会亮` |
| 缺必填格 | `第 4 块：缺少"赢法"` |
| 名字重复 | `"A 点快打"和已有的第 3 条重名，建议改成"A 点快打 · 双烟版"` |

校验通过后：**能匹配的组合拳卡片多一条**，卡片上标 `自建`，并且会进入 AI 的结构化事实（`facts.combos`），AI 讲战术时会引用它。自建的存本机 `localStorage`，导出按钮可以把它们打包成 JSON 给你备份/分享。

## 七、和现有数据结构的映射

现有 `VD.COMBOS` 一条长这样：

```js
{ id, map, site, side, title, requires: [], difficulty, 
  steps: [{ t, agent, ability, target, why }], win_condition, countered_by: [], source }
```

模板新增三个字段（都是可选，旧的 14 条不用改）：

```js
steps: [{ t, agent, ability, from, target, why }]   // + from：站哪放
{ patch, swaps, variants, author, origin: 'user' }  // patch 版本、swaps 替代、origin 标自建
```

`requires` 就是"必需英雄"（存英雄 id，不是中文名，导入时做一次中文名→id 的转换）。`可选替代` `变阵` 只影响展示。

## 八、这一版明确不做

- 不做"上传点位截图"（要图床 + 坐标标注，是另一个量级的活）；
- 不做多人协作 / 云端保存（自建只存本机）；
- 不做自动从视频里抽点位；
- 不改现有 14 条组合拳的写法。

## 九、需要你决定的 5 件事

1. **"释放位置"要不要拆成"从哪站"和"落到哪"两列？** 我倾向拆（半墙/跳投全靠这个区别），但表会宽一列。
2. **要不要"触发条件"这一列**（如"等对面进 A 大后 1 秒再丢"）？能让拳更精确，但很多人写不出来，会空着。
3. **导入格式先做哪种？** 我建议先做方式 A（Word → .htm），如果你习惯 Excel 就优先 B。
4. **自建组合拳要不要标作者**？标了分享给别人有署名，但涉及"谁写的靠谱吗"。
5. **必填卡到多严？** 我建议"名称 / 地图 / 阵营 / 目标区域 / 必需英雄 / 赢法 / 每步的 谁+技能+打到哪+为什么"必须填，其余可选。太严没人愿意填，太松导入进来就是垃圾。

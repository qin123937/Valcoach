# 阵容教练 · Comp Coach

无畏契约（VALORANT）阵容分析器。**选完 5 个英雄，立刻知道这套阵容该怎么打。**

不是"强度榜"，也不是"点位库"，而是把阵容拆成能力向量，跟地图需求比，算出**缺口**，然后告诉你这张图上这套人**能打出哪些组合拳**、**第 5 个人该补谁**。

## 怎么打开

双击 `index.html` 就行 —— 零构建、零依赖、纯静态，不需要 Node、不需要装包、不需要起服务器。

（Chrome / Edge / Firefox 都可以。数据走 `localStorage`，换浏览器要重新选人。）

## 你会看到什么

| 区块 | 在算什么 | 为什么要它 |
|---|---|---|
| **阵容体检** | 8 维能力向量（烟/闪/信息/硬控/机动/续航/守包/经济）5 人合计 vs 亚海悬城需求，加权算覆盖度 0–100 | 把"感觉打不动"变成"烟只有 60%" |
| **结论 / 缺口** | 硬缺口（<60%）与偏弱（<85%）分开，角色结构单独判 | 区分"能用但要靠枪"和"结构就错了" |
| **组合拳** | 每条 combo 的 `requires` 全在阵容里才算可用；差一个英雄的单独列成"差一个就能用"；**可以自己写**（顶栏「战术」） | 这是本工具的核心：不推荐英雄，推荐**道具怎么连** |
| **第 5 人推荐** | 先补齐缺失位置，再比边际收益 Δ（不是强度）；卡片会标「补哨卫位」/「可顶哨卫」 | 4 缺 1 时最有用 |
| **AI 教练解读** | 把上面这些结论压成结构化事实，交给 LLM 写成"人话战术" | 规则负责算准，模型负责说人话 |
| **英雄档案** | 点英雄池里名字右侧的 `i`：头像、职业说明、技能（**国服名 + 用途**）、可展开的接口原文、本项目的点评 | 想知道这家伙的道具到底怎么用，不用再开别的站 |
| **官方地图** | 地图介绍下面那张图：valorant-api.com 的俯视地图（游戏内小地图），可点开原图 | 说烟封在哪、谁从哪进，先得有共同的名字 |

## 游戏资产从哪来

`js/assets.js` 在打开页面时请求公开接口 [valorant-api.com](https://valorant-api.com)（社区维护，非 Riot 官方）：

- 特工头像（`displayIcon`）、半身像（`fullPortrait`）、职业图标（`role.displayIcon`）、技能图标与原文描述；
- 亚海悬城的官方地图图（`splash`），当作阵容卡片的横幅。

三条硬规则：

1. **资产不参与打分**。头像拉不到就退回字母头像，地图图拉不到就退回纯文字，分析和推荐结果完全不受影响。
2. **结果缓存 7 天**（localStorage `vd.assets.v1`），所以第二次打开基本不请求网络。
3. **技能名一律显示国服叫法**。档案里的技能列表用的是 `data/agents.js` 里整理好的国服名（如猎枭 寻敌箭 / 炼狱 空投烟幕 / 捷风 逐风），名字对齐官网 game-data 页与无畏契约 BWIKI。接口返回的中文原文多数与国服同源，但个别新英雄接口里还没有条目或叫法不同（例如遐思 Hush），所以原文被收进折叠的「官方技能原文」里只作补充，不占主位，也不参与任何计算。

匹配方式：用英文名（`en` 字段，如 `Jett` / `KAY/O`）去对接口里的 `displayName`。接口新增的英雄如果没在 `data/agents.js` 里，会被忽略；反过来，本项目里的英雄如果在接口里对不上名（新英雄、译名差异），就自动只用字母头像。

这三位新英雄的 8 维向量是我按技能机制估的（幻棱 mobility 5、迷核 smoke 8、遐思 flash/control 4），**属于可调的猜测值**，觉得不对就点「调参数」或直接改 `data/agents.js`。

## 怎么改

全都是普通 JS 数据，**打开就能改，改完刷新**。

### 调英雄强度

`data/agents.js` 里每一项的 `vec` 是 8 维分数：

```js
vec: { smoke: 9, flash: 0, info: 0, control: 0, mobility: 0, sustain: 1, postplant: 5, econ: 4 },
```

量程不一样，别用同一把尺子看：

- **烟是 0–10 分**，标定规则是「**一个控场 ≈ 一张图的烟需求**」，所以单控场阵容不会因为"只有一个人会放烟"就被判成硬缺口。
  当前取值的依据：幽影 / 星礈 = 10（远程、可反复放），炼狱 / 海神 = 9，蝰蛇 / 暮蝶 = 8（一次性、需要占位）；
- 其余 7 维是 0–5 分，5 表示"这一维他就是天花板"。
- **经济（econ）这一维不单独拆"可复用性"，而是把它和价格合在一起算**：它衡量的是"没钱回合这个英雄还能不能拿出核心道具"。免费签名、每回合自动恢复、击杀重置的道具都算便宜（等于不花钱），要靠现买、价格 300 以上的一次性道具算贵。
  据此：幽影（黑瘴免费两充能）、蝰蛇（毒幕燃料制）、暮蝶（霞染免费、死了还能放）从 3 提到 4，迷核（声波帷幕免费签名两充能 + 一发只要 100）提到 5；猎枭（寻敌箭免费）、星礈（星云免费）、幻棱（溯流回光击杀 2 人重置）、遐思（念落星移击杀 2 人重置）从 2 提到 3。

觉得炼狱烟太强就改小，推荐结果会立刻跟着变。这里没有"官方数字"，它就是一张**可调的校对表**。

烟的权重 `w` 在 `js/engine.js` 里（默认 1.35，是 8 维里最高的）；冗余判定对烟单独放宽到 2 倍，因为双控场的烟量天然接近一张图需求的两倍。

### 不想改文件？点顶栏「调参数」

点右上角 **调参数** 会弹出面板，30 个英雄 × 8 维全是数字框，直接改就行：

- 改完立刻重算（覆盖度、缺口、雷达图、第 5 人推荐都会跟着变），**不用刷新、不用碰文件**；
- 改动存在本机 `localStorage['vd.vec.v2']`，下次打开还在；
- 单个英雄想撤回就点它右边的 `↺`，「全部恢复默认」清空所有改动；
- **「导出 JSON」** 把改过的英雄导成 JSON，想永久固定就抄回 `data/agents.js` 的 `vec`；
- 允许 0.5 档，烟最多 10、其他维最多 5，超出的值会自动夹回去。

注意：调参数改的是**本机覆盖值**，`data/agents.js` 本身永远不变——所以分享给别人时，要么让他自己调，要么把导出的数字合并进数据文件。

### 不想改文件？点顶栏「战术」——自己写组合拳

点 **战术** 会弹出面板，上半是"我建的"（空的时候只有一行提示），下半是"内置"的 14 条（写死在 `data/ascent.js`，只能看不能改）。

新建一条的流程：

1. 填**名称**、**阵营**（进攻/防守）、**目标区域**（A/B）、**难度**；
2. 加**步骤**：每一步选「几秒 / 谁 / 什么技能 / 打到哪 / 为什么」。
   - 「谁」是 30 个英雄的下拉，「什么技能」会**跟着那位英雄变**——所以你不可能写出"猎枭的嗜血"这种错配；
   - 「打到哪」有这张图点位的自动补全（A 大 / 天堂 / 中连…），也可以自己写；
3. 填**赢在哪 / 会被什么破 / 来源**，点保存。

几个"替你兜住"的设计：

- **必要条件自动生成**：不再手写 `requires`，而是"步骤里用到谁，就必须阵容里有谁"；
- 保存后会立刻出现在「可用组合拳」里（自建的会挂一个青色的 **自建** 角标，卡片里带「编辑 / 删除」按钮），并且一起进 `buildFacts` 交给 AI 当依据；
- 存在本机 `localStorage['vd.combos.v1']`，**不碰任何文件**；浏览器不许存盘时面板顶部会明说"改动只在本页有效"；
- **导出 JSON** 把自建的部分导出，**导入** 支持把 JSON 粘回文本框再点一次（换机器 / 发给朋友用这个）；
- 校验会直接告诉你错在哪：比如"第 2 步：猎枭 没有「震荡箭」，可选：枭型无人机 / 雷击箭 / 寻敌箭 / 狂猎之怒"。

想永久内置（让所有人都看到），还是把它抄进 `data/ascent.js` 的 `VD.COMBOS`——字段和面板里的一模一样。

### 英雄兼职（一个英雄顶两个位）

英雄条目上可以加 `alt`，表示"本职不变，但某个位置空缺时能顶一部分"：

```js
{ id: 'viper', name: '蝰蛇', role: '控场',
  alt: [{ role: '哨卫', why: '毒幕能切掉一条进点路线，蛇吻能封拆包、逼对面等毒散' }] }
```

现在的规则（只有蝰蛇带了兼职）：

- **角色结构上她还是控场**——双控场判定、烟的需求计算、8 维打分全都不变，不会因为兼职就变成哨卫；
- **队里一个哨卫都没有时**，角色区会从"没有哨卫（黄）"降级成提示"没有专职哨卫，但蝰蛇能顶一部分：……"，不再当成结构性短板；
- **第 5 人推荐里，能顶空缺职责的英雄会往前排**，卡片上会挂一个「可顶哨卫」的标签，理由行会多一句"兼哨卫位"；
- 英雄档案里也会显示这一行兼职说明。

### 第 5 人是怎么排序的

排序分三层，**先结构、后数据**：

1. **能不能补上缺的位置**（`fillTier`）：本职正好是空缺位置 = 2，靠兼职顶 = 1，补不了 = 0。这一层优先级最高——缺哨卫时，一个数据一般的哨卫会排在一个数据很好的第二个先锋前面；
2. **加权收益 `rank`** = 覆盖度 Δ + 结构加分（补空位 +8，兼职顶 +3）。这里的 +8 就是"阵容完整度的权重"，想再提高就改大；
3. 最后才比总分 `score`。

卡片上的 Δ 永远是**真实的覆盖度变化**，不含结构加分——所以你会看到 Δ 更小的人排在前面，这是有意的。

改权重的位置：`js/engine.js` 的 `recommend()` 里

```js
const fillTier = primaryFill ? 2 : (roleFills.length ? 1 : 0);
const structBonus = primaryFill ? 8 : (roleFills.length ? 3 : 0);
```

### 调地图需求

`data/ascent.js` 的 `need.attack / need.defend`，单位跟英雄向量一致（5 人合计）。数值越大 = 这条边越吃。

当前经济（econ）需求是**进攻 14 / 防守 15**。这一维要按"5 个人加起来能掏出多少道具预算"来标，不能按单人量级标——旧值 10 / 11 相当于两个人就填满，经济永远不会成为短板。现在的标定是：常见阵容 5 人 econ 合计在 15~19，满覆盖；合计 13 以下开始擦线；全选"每回合要现买"的英雄（合计 10~11）才判"偏弱"，合计 8 以下才判硬缺口。（试过 16 / 17，实机上偏严，已回调。）

### 加一张图

1. 往 `VD.MAPS` 里加一条（要有 `id / name / need.attack / need.defend`）；
2. 往 `VD.COMBOS` 里加 combo，`map` 填新 id；
3. `js/app.js` 顶部 `const MAP = 'ascent'` 改成新 id。

### 地图图从哪来 / 怎么换

那张图不是我自己画的，是 valorant-api.com 的 `maps[].displayIcon`——也就是游戏里那张俯视小地图，直接从免费接口取：

- 第一次打开页面联网拉一次，之后缓存在本机 `localStorage` 里 7 天，断网也能看；
- 拉不到（断网 / 被墙 / 第一次还没加载完）会显示一行提示，不会白块；
- 点图可以打开原尺寸 PNG。

想换成本地截图（比如你自己标了点位的那张）：

1. 把图片放到 `assets/` 目录，例如 `assets/ascent-map.png`；
2. 在 `data/ascent.js` 的地图对象里加一行 `localMap: 'assets/ascent-map.png'`（相对 `index.html` 的路径）。

有了 `localMap` 就优先用本地图，接口图只做兜底。

想在官方图上标点位名，最省事的做法是用截图工具在图上画好再存成 `localMap`；如果要做成可交互的标签，就在 `mapShot()` 返回的 HTML 里给 `.map-shot` 加一层绝对定位的 `<span>`（`.map-shot` 已经是 `position: relative` 的容器就能对齐）。点位名一律用**国服叫法**（A 大 / A 大厅 / 天堂 / 发电机 / 酒窖 / 树屋 / 中庭 / 中连 / 市场 / B 后 …），因为这些名字同时是 AI 能用的点位白名单（`callouts`）。

### 加一条组合拳

```js
{
  id: 'a-exec-brim-sova-jett',
  map: 'ascent', site: 'A', side: 'attack',
  title: 'A 点双烟速攻',
  requires: ['brimstone', 'sova', 'jett'],   // 必须在阵容里
  difficulty: 2,                              // 1~3
  steps: [
    { t: 0, agent: 'brimstone', ability: '空投烟幕', target: 'A 大出口 + 天堂', why: '…' }
  ],
  win_condition: '…',
  countered_by: ['…'],
  source: '…'
}
```

`t` 是秒（相对起手的偏移），`why` 写**为什么这个时机**，不是复述技能。

## AI 部分怎么工作

- **你自己带 Key**：右上角「API 设置」，可以先用「快速填入」选一家，再填 Key。请求从浏览器直发，没有中间服务器。
- **配置不依赖 localStorage**：填完点保存后，配置立刻存在页面内存里（`aiConf`），本次会话马上可用；`localStorage` 只是"顺手记住"，浏览器禁掉它（`file://` 下常见）也不影响使用，只是刷新后要重填——页面会明确告诉你这一点。
- **点「测试连接」能直接看到真实错误**：`HTTP 401 / 404 / 429`、超时、或者被 CORS 拦截，都会分类型给出说明，不用猜。
- **最常见的失败原因是 CORS**：用 `file://` 双击打开时，请求的 `Origin` 是 `null`，不少模型接口会直接拒绝，浏览器的表现是 `TypeError: Failed to fetch`，看起来像"功能没实现"。解决办法按优先级：
  1. 在该文件夹起一个本地服务器再打开（`npx serve` / VS Code 的 Live Server / `python -m http.server`），地址变成 `http://localhost:3000` 之类；
  2. 换一家允许浏览器直连的接口（Gemini 的 OpenAI 兼容端点、OpenRouter 通常可以）；
  3. 本地 Ollama 要设环境变量 `OLLAMA_ORIGINS=*` 才允许跨域。
- **永远有兜底**：请求失败时，「AI 教练解读」会显示失败原因 + 建议，然后给出**离线版结论**（同一套 schema，由规则引擎根据事实直接生成），按钮可以重试。所以这个区块不会变成空白。
- **防胡说**：发给模型的只有规则引擎算出的事实（维度覆盖、缺口、命中的 combo、第 5 人候选），系统提示明确要求「不要编造数值和技能、combos 为空就说缺什么、不要推荐事实里没有的英雄」，返回强制 JSON，前端按字段渲染。

## 已知限制（诚实说明）

1. 英雄向量和 combo 都是**人工整理的当前版本数据**，不是官方数值，也不跟补丁自动更新 —— 这是刻意的：数值可调，比假装精确更诚实。
2. 只做了**亚海悬城**一张图。这是刻意的首期范围：先把一张图的组合拳写厚，再复制到别的图。
3. 组合拳匹配是**集合包含**，不理解"谁先手谁后手"的经济约束（比如双决斗抢同一个烟）。
4. AI 解读的质量取决于模型本身；规则引擎的结论是硬的，模型只是把它翻译成战术语言。
5. **这个项目没有在你的浏览器里跑过验证**（开发环境没有 shell/浏览器）：逻辑是静态审查 + 页面内全局报错红条兜底。如果顶栏出现红条，把那行字发我。
6. **自建战术只存在你这台机器**（`localStorage['vd.combos.v1']`），换浏览器/清缓存就没了 —— 想留住就用「导出 JSON」存一份，或者把它抄进 `data/ascent.js` 变成内置。
